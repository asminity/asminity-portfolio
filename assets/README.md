# Portfolio Assets

This directory stores visual assets and static media used throughout the portfolio website.

### Guidelines:
- Store optimized images, diagrams, or icon files here.
- File naming convention: lowercase with hyphens (e.g., `project-preview.webp`).
- This website primarily leverages lightweight CSS-driven illustrations, SVG iconography, and Bootstrap Icons to ensure near-instant load speeds without external image dependencies when hosted on GitHub Pages.
